# 新水旋涡模型：去水面与水色试制

日期：2026-10-27。来源为作者提供的 `D:\Data\Blender Models\Water Vortex_tut_Appended_4.5.blend`；原文件未修改。该素材与此前水带式龙卷是两套模型，不能混用此前的实机验收结论。

## 检查与处理

原模型是几何节点生成的整张方形网格：中心向下凹陷形成漏斗，外侧保留起伏水面。因此水面并非可单独删除的对象。节点输出前增加半径裁切，阈值 0.78，保留中心凹陷和口沿。实际离散面边界最大半径约 0.787；整体外围水面已排除。网格由 181×181 提升到 501×501，以改善俯视水纹与外缘的细分密度。

新场景 `WaterVortex_Clean_24` 与原场景分开，模型名为 `WaterVortex_Only`，独立节点树为 `WaterVortex_Trimmed_Loop24`。带“外围水面裁切半径”标签的比较节点可调整裁切范围，裁切未破坏原几何节点生成过程。

材质以深度和表面法线控制七阶水色色板：深蓝中心、青蓝主体、浅青高光。当前采用适合像素烘焙的自发光着色，不依赖额外灯光，也不是物理透射水材质。外部透明，漏斗中心为深色实体表面，不是透明孔洞。

原动画仅在整体扭转角度上叠加时间，没有独立的逐帧流体模拟。保留其几何和旋转方式，用 `2*pi*((frame-1)%24)/24` 驱动 24 帧一圈。初次线性时间方案产生 25 个像素的接缝差异，已改为取模相位精确归零，重新渲染后差异为 0。

- `WaterTornado_24_vertical.png`：400×9600 的交换用长图，游戏优先使用网格图集。

文件前缀沿用已有打包工具的 `WaterTornado`，内容为本目录新漏斗旋涡，不是上一版水带模型。

## 重做

在 Blender 打开源模型或切换到包含原始 `Plane` 的附加场景后，执行 `Tools/WaterSprite/prepare_vortex_model.py`。随后使用 Pillow 12.3 的 Python 执行 `Tools/WaterSprite/pack_frames.py --vortex-model`。输出路径定位于当前仓库。重复执行会创建额外场景，建议从源文件开始重做。

## 验证边界

已查看侧面、俯视渲染和24帧总览，确认方形水面去除、漏斗保留。离线验证 24 帧不同、外缘无画面裁切、第 25 帧与首帧像素差为 0。当前完成模型加工与试渲染，未对新模型执行 TML 实机显示、相机缩放、战斗挂接或联机测试。主体较上一版连续，外围密集细纹在缩小时仍可能丢失，后续接入需按实际显示直径检查。
