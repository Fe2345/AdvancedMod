# 共鸣虚影材质初稿

运行 `Tools/Generate-HallowPhantom.py` 可重新生成，依赖Pillow。轮廓由参数化多边形绘制，不依赖生成式图片服务；原剑仅用于预览对照。

- 资源目录：`Assets/Textures/Hallow/HeavensJudgmentPhantom{Front,Side,Glow}.png`。
- 三层均为64×256透明白色遮罩，PNG使用直通Alpha，后续由内容管线预乘。正面内部纯白，使用绘制颜色染为对应元素；光晕仅改变透明度。
- 握点(32,204)，剑尖(32,12)，长度192，与现有武器攻击半径一致；下方剑柄延伸至232。保留细长尖锋、轻微不对称刃线与根部外展轮廓，横护手34×5。
- 侧面标称厚度2.5像素，用于后续绕纵轴旋转的厚度表现。预览仅用cos压缩正面、sin显露侧面；游戏已接入椭圆轨道投影、透视缩放、深度排序及分阶段动画；材质本身仍为二维正面和厚度侧面。
- `preview.png` 为2倍尺寸展示，包含原剑、正面与45°／75°／90°示意，以及雷／火染色。侧面较暗但保持相同色相。
- 本轮生成和透明边界检查通过，预览已检查；已替换共鸣虚影及反击绘制，本体贴图不变；本轮新动画实机验证另记。

动画已接入：45刻抬剑展开，静止30刻，在第75刻同步提交元素与颜色，再顺时针旋转收回45刻，共120刻。展开和收回分别顺时针一圈，环绕半径随阶段展开与收束，剑身保持竖直。
