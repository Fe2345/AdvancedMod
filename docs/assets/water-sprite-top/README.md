# 水旋涡俯视像素动画

2026-10-27：根据作者提供的 `水龙卷.blend` 制作。从 **+Z 轴朝 -Z 轴** 正交观察，图像上方对应 +Y，右方对应 +X。原始 Blender 场景保留；编辑副本为 `WaterTornado-Top-400.blend`，进入 `WaterSprite_24` 场景查看。

## 文件与规格

- `WaterTornado_24_grid.png`：推荐运行时资源，6 列×4 行，2400×1600。按行从左到右读取，共 24 帧。
- `frames/WaterTornado_00.png` 至 `23.png`：各帧 400×400，透明 PNG，固定 15 色，Alpha 仅 0／255。
- `WaterTornado_24_vertical.png`：400×9600，仅作为交换格式。不要默认将该长图作为兼容各显卡的游戏资源。
- `WaterTornado_preview.gif`：24 帧一秒循环，深色背景仅用于预览，PNG 保持透明。GIF 受 10ms 时间粒度约束，使用 40／50ms 组合保持整圈 1 秒。
- `contact.png`：24 帧总览，缩小到每帧 200×200。
- `manifest.json`：色板、图集规格、各帧边界、循环检查结果。
- `raw/`：原始渲染，额外第 25 帧只用于与首帧比较，不进入最终动画。

## 制作与使用

在 Blender 中打开原模型，执行 `Tools/WaterSprite/render_blender.py`；随后在装有 Pillow 12.3 的 Python 中运行 `Tools/WaterSprite/pack_frames.py`。脚本会另建场景并保存副本，不覆盖原始模型文件。重复执行会另建场景，因此重做时优先从原文件开始。

素材取原模型第 33 帧的几何，按原材质分成三层，分别旋转 1／2／1 圈。动画是分层旋转循环，并未复刻原几何节点的非周期时间形变。表面法线驱动阶梯式水蓝色明暗，原黑色未连接材质层替换为深蓝色。

游戏取帧：`frame = floor(seconds * 24) % 24`；源矩形为 `(frame % 6 * 400, frame / 6 * 400, 400, 400)`。画面原点取单帧中心 `(200,200)`。使用 `PointClamp` 保持像素边缘，贴图没有模糊插值和颜色抖动。最终在 200 像素显示时是 0.5 倍采样，在 400 像素显示时为 1:1；实际屏幕尺寸还会受世界相机缩放影响。

本次暂不替换已有程序化水体实验或绑定正式反应。侧视初稿在相邻 `water-sprite` 目录留作历史对照，以本目录俯视版为当前规格。

## 验证

离线已检查：24 帧全部不同、各帧无边界裁切、循环第 25 帧与第 1 帧像素差为 0。实机对照由 `Tools/WaterSprite/Run-Tml.ps1` 启动隔离测试存档，以环境变量启用 `WaterSpritePreviewSystem`。已在真实 TML D3D11、1280×900 画面中检查 200／300／400 屏幕像素显示，截图和结果在 `docs/testing/water-sprite`。400 保留更多外围细丝，200 仍能辨认主要旋涡；建议先以 300 左右屏幕像素展示并保留 400 源图。当前是顶层叠加检查，正式世界实体、相机缩放、遮挡与联机尚未验证。
