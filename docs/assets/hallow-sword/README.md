# 天裁剑身生成记录

生成方式：内置 image_gen，参考用户提供的剑形截图，transparent_background=true。源图保存在本目录generated-source.png。

提示词：单把完整竖直剑，剑尖朝上、剑柄朝下、正交正视；细长青绿翡翠剑刃，浅薄荷色锋缘、深青色中脊；参考图的流线圆形卷曲护手，少量浅金点缀，白青剑柄，无剑穗。整体细长，适合约200像素游戏资产。透明背景，无文字、阴影和背景图案，清晰手绘游戏风格。

程序处理：Tools/Prepare-HallowSword.py，保留并清理真实Alpha，移除低透明度背景残色，超采样缩放到48×240。源握点(512,1280)、源尖端y=36，目标握点(24,196)、目标尖端(24,4)。对应握点到尖端192像素；护手宽约28像素，剑刃宽约8像素。另生成48×48物品图标。

游戏绘制：以握点为原点，旋转角=挥刀角+π/2，缩放=实际攻击半径/192，保证剑尖贴合轨迹外缘。Alpha预乘交给游戏资源管线。
