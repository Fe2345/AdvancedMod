# 水体实验性能与验证报告

日期：2026-10-27。原始结果位于 `docs/testing/water/perf-*.json`，每个文件对应一次真实窗口运行，不是理论估算。

## 环境与测量方式

- CPU：Intel Core Ultra 9 275HX；24 逻辑处理器；内存约 31.4 GB。
- GPU：NVIDIA GeForce RTX 5060 Laptop GPU，由 FNA3D 实际启动日志确认。`GraphicsAdapter.Description` 另显示 Lenovo DisplayHDR（显示设备名称），不将其当 GPU 型号。
- Windows 10.0.26200；独立程序 .NET 8，FNA 23.10，D3D11，Release 构建；窗口 1000×760，VSync 关闭，非固定更新步长。
- 每配置 150 帧，跳过索引 0–30，统计其余 119 帧。Stopwatch 包围 CPU 场计算、浮点纹理上传和绘制提交；不包含 Present、截图编码或 Update。上传或驱动调用可能阻塞，因此这不是纯数学内核时间，也不是 GPU 时间或帧率。
- 单实例显示 640×640；多实例分散布局按 180/215/250 像素变化，重叠布局为 400×400。单实例两种布局实际相同，可看作重复样本。
- 完整旋涡默认参数（Width=0.15，Branch=0.12），每实例两个独立深度层。不使用事先烘焙动画；没有截屏回读混入本表。
- 普通桌面环境测量，未锁频、未清空其他应用、没有统计置信区间。不同时间段有调度和温度噪声，不用微小差异推断重叠布局更快或更慢。

## 生命周期与正确性证据

- `offline.json`：10/10 通过。相同时间与种子逐浮点一致；真实遮罩连通分量从 2 到 1 再到 2；180 个 30Hz 样本有界，原始场相邻变化有上界；稳态 Generate 30 次零托管分配；实例数组隔离；错误/有效 shader 编译路径。
- `lifecycle.json`：暂停相邻两帧 GPU 回读逐像素一致；窗口改为 840×620、正反转、明暗背景、128/512/256 和 10/1/5 实例切换实际执行。每帧检查应用持有水体纹理为 `2×实例数`，卸载后为 0。
- `reload.json`：实际语法失败与接口不兼容均被拒绝，旧 Effect 保留，有效 Effect 两次替换成功。旧 Effect 在绘制线程释放。
- 资源数量为应用对象计数，不是图形调试器显存快照。没有长时间压力测试，不能据此证明驱动无泄漏。主循环仍有标题字符串等托管分配，“零分配”只指 CPU 形状场 Generate。
- `docs/assets/water/` 包含两种预设真实截图及 GIF、明暗背景、主层六视图；`tml-fusion.png` 是实际 TML 测试存档画面。

运行命令：

```powershell
pwsh -File Tools/WaterPreview/Benchmark.ps1
dotnet Tools/WaterPreview/bin/Release/net8.0/WaterPreview.dll --test
dotnet Tools/WaterPreview/bin/Release/net8.0/WaterPreview.dll --bench --shaded --reload-test --frames 1000
dotnet Tools/WaterPreview/bin/Release/net8.0/WaterPreview.dll --bench --shaded --vortex --exercise --frames 320
pwsh -File Tools/WaterPreview/Run-Tml.ps1
```

测试期间曾在旧程序运行时修改 shader 参数协议，导致一次 512×10 测量中止；没有把中止结果记为通过。增加接口校验后重新测试成功。热重载/截图/混合配置生命周期运行单独写入 `*-run-*.json`，不参与性能表。矩阵中后续修订的光流参数和屏幕 UV 均已再运行验证；表中各配置是本轮分批测量，并非同一时刻快照。

## 尚未验证

GPU timestamp、OpenGL/Vulkan、长期显存、多人联机、其他模组与世界遮挡、相机旋转法线、多层水体相互折射均未验证或未实现。TML 测试仅覆盖最小屏幕位置与显式背景混合，不能当作正式玩法接入验收。
