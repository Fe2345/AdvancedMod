# 神圣毁灭者巡航与冲撞调研

日期：2026-10-30。状态：源码调查和一维运动估算完成；下述参数均为待确认、待实机试验的候选值，没有修改运行时 AI 或 Hallow.md 的设计。

后续实施更新：作者已批准进入无技能弹幕的二阶段运动试验，采用14／21速度、平滑加减速与距离／朝向共同决定起步；静止及移动目标流程验证通过。下面保留原调查与候选范围，当前实现和验证边界以 [二阶段验收](testing/destroyer-phase2/README.md) 为准，尚未完成完整战斗手感调参。

## 设计前提

当前 Hallow.md：一阶段近似原版；二阶段 Crash—Crash—Idle，Crash 提速 50%，头部距玩家 1024 像素内触发随机弹幕。这个 1024 是弹幕资格范围，不必兼作冲撞起点。暂按机械三王阶段、常规跑鞋和早期翅膀、无无限飞行及必备冲刺饰品设计。

本机 Player 源码中闪电靴、霜花靴、泰拉闪耀靴对应的 accRunSpeed 为 6.75；翅膀、坐骑和其他修正有自己的路径，不能把此字段当成所有方向的真实速度。本报告以水平持续移动 6—8 像素/刻为普通测试档，10—12 为额外高速压力档；后者不是所有玩家的默认能力。玩家转向、飞行剩余时间和安全落点比单独最大速度更重要。

现有毁灭者运动基线速度 16，间距 44×scale，普通链有 80 个身体和一个尾部，加头约 82 节。scale=1 时约有 3564 像素的头尾路径长度，不能照搬短虫的立即折返。21 速度下，一个头部经过点仍可能在约 2.8 秒内被后续身体陆续经过，实际时间取决于曲线路径和速度。

### Fargo 永恒毁灭者：最贴近战斗进度与实体结构

[Destroyer.cs](https://github.com/Fargo-Team/FargosSoulsMod/blob/master/Content/Bosses/VanillaEternity/Destroyer.cs#L236)

- NonCoilAI 基础 maxSpeed=16，常态非 fastStart 时距离小于 600 将目标速度减半，大于 900 将两项运动系数翻倍。
- 玩家位于前方 ±45° 且移动较快时，将目标速度提升至玩家速度的 1.5 倍。这是有朝向门槛的追赶，不是任何方向都实时提速。
- 另有位置增量 npc.position += npc.velocity * (0.5 - flySpeedModifierRatio)，随血量等变化，故 maxSpeed 不能直接当最终每刻位移。
- 激光冲击段有 120 刻预警；接近过程中目标速度至少 24，两项转向／加速系数乘 10。进入 400 内后显式设速度 20，并在非受虐模式偏转 30°。
- 此后玩家不在前方时削弱转向、以 0.986 乘速度减速，并施加轻微曲转。400 表示接近后的动作切换，不是通用的冲撞发车距离。

适合借鉴：距离分层、朝向判定和掠过后的有限转向。它仍有直接设速度／方向的时点，不能称为全程平滑范本。

### Infernum 渊海灾虫：把转向期和正式冲撞分开

[AquaticScourgeHeadBehaviorOverride.cs](https://github.com/InfernumTeam/InfernumMode/blob/master/Content/BehaviorOverrides/BossAIs/AquaticScourge/AquaticScourgeHeadBehaviorOverride.cs#L528)

BubbleSpin：接近 75 刻、盘旋 270 刻、转向 33 刻、正式冲撞 56 刻；基础盘旋速度 23、冲撞 30.5。转向逐刻 Vector2.Lerp(..., 0.08)，最后一刻仍直接赋目标速度。该技能非冲撞期 npc.damage=0。不能只抄 30.5，却删除无接触伤害的准备期。

WallHitCharges：基础 25，后续准备 30 刻，首次额外 60 刻；准备使用时间平方曲线和 0.08 速度插值，撞墙／超时后有停顿。另一个 GasBreath 分支将期望速度按距离 640—3000 插值到 14.5—38，并分别处理速度和转向。

适合借鉴：单独的准备窗口、速度与转向分开控制。即使同为月前实体，Infernum 的难度、环境和无伤窗口也使其数值不能直接作为普通机械阶段基准。

### 灾厄风暴编织者：月后参照，只借结构

[StormWeaverHead.cs](https://github.com/CalamityTeam/CalamityModPublic/blob/1.4.4/NPCs/StormWeaver/StormWeaverHead.cs#L331)

二阶段基础速度 12，专家／复仇分别额外 +1／+1.5；冲撞按难度和阶段的时钟开启，提前 70 刻发声音。冲撞补速含距离×0.01×失血因子，再整体翻倍；越过玩家横向约 800 或冲撞窗口超时退出。复仇入口还有直接设置冲撞速度的分支。

## 建议先试的参数与切换

全部距离使用头部中心到目标玩家中心的世界像素，16 像素为一格；不是到最近身体的距离。

| 项目 | 首轮候选 | 作用 |
| --- | --- | --- |
| 巡航 / 冲撞速度 | 14 / 21 | 保留提高 50%；16 / 24 作偏快对照组 |
| Idle 持续 | 120—180 刻 | 两次 Crash 后的恢复和输出时间 |
| 整理位置的目标距离 | 约 1000—1200 | 从玩家侧面画弧形成跑道，不直接朝脸慢推 |
| 正式加速起点 | 900—1100；容许上沿 1200 | 约 56—69 格；不是进入此圈就无条件触发 |
| 起步条件 | 预警至少 30—40 刻且夹角≤15° | 在真正加速瞬间重新检查距离 |
| 平滑提速时间 | 30 刻，试调范围 24—36 | 约半秒，保留入场速度 |
| 巡航 / 整理朝向上限 | 约 2—3°/刻 | 与速度分开调，不无限追踪 |
| 正式冲撞朝向上限 | 0—0.5°/刻 | 方向锁定或仅小幅校正，穿过目标后不追头 |
| 玩家速度预判 | 10—16 刻，上限 128 像素 | 发动时一次性取样；不是全程持续拦截 |
| 收招 | 越过锁定点 400—600，且已拉开；最长 120 刻 | 正常通过后结束，玩家远离时也不能无限冲 |
| 两次 Crash 间整理 | 至少 45—60 刻并重新满足起步条件 | 不是完整 Idle，但必须重新画弧对齐 |
| 减速时间 | 36—48 刻 | 逐渐回到巡航速度，不清零再启动 |

小于 640 像素时不新开一次高速冲撞：先以巡航画弧拉开。超过约 1600 时允许单独追赶并暂停攻击资格，可用平滑过渡将巡航提至 18 左右，但不把该补速继续叠乘进 Crash 的 21。以上均非确认规则。

“准备 30 刻”不是在 1000 像素处一直向玩家飞 30 刻，然后无条件冲撞；那时可能已贴脸。预警放在画弧整理阶段，起步距离和夹角在正式加速时再验。超过整理时限仍不满足时继续重定位，不强制贴脸发车。

外层仍为 Crash—Crash—Idle；每个 Crash 内部含整理、预警、加速、穿越、恢复步骤，不必把这些都扩成顶层技能。

正式发动时锁定目标点 Q 和冲撞方向 d。用 dot(头部位置-Q,d)>400—600 判断是否越过，再结合当前玩家距离和最短冲撞时间，避免把“玩家主动远离”误判为已经穿过。120 刻是兜底上限。长链需要检查下一次路径是否横切仍留在玩家附近的旧身体，不要求机械地等整条尾部通过。

## 为什么从 900—1100 开始

采用 14→21、30 刻 SmoothStep 提速，一维估算如下。玩家以 7 像素/刻朝向／静止／背离 Boss；计算到两者中心重合，不考虑碰撞尺寸、转向、跳跃和弹幕，所以实际接触会更早。这不是游戏测试。

| 起点距离 | 玩家迎面移动 | 玩家静止 | 玩家同向远离 |
| --- | --- | --- | --- |
| 640 | 27 刻 / 0.45 秒 | 36 刻 / 0.60 秒 | 54 刻 / 0.90 秒 |
| 900 | 36 刻 / 0.60 秒 | 48 刻 / 0.80 秒 | 72 刻 / 1.20 秒 |
| 1100 | 44 刻 / 0.73 秒 | 58 刻 / 0.97 秒 | 87 刻 / 1.45 秒 |

因此 400—600 的近距启动叠加弹幕很容易挤掉反应窗口；900—1100 加独立预警更值得先试。另一方面也不应随意升到 1800—2400，头可能长期在屏外，迫使玩家只凭声音判断。以常见 1920×1080、100% 镜头为例，距玩家中心向上 900 已远超半屏高度，必须给 PhaseII_Prepare 和屏外进场可见方向提示，不能假设“距离大就公平”。

本项目在机械阶段没有理由先假设玩家能稳定以月后水平飞行或连续冲刺；对高速坐骑等另设压力用例，不随玩家每一帧瞬时冲刺速度无上限拉升 Boss 速度。

## 如何让加速和回转不生硬

把速度大小和方向分开处理。进入状态时保存实际 speed0，不能每刻重新取 speed0 重新开始插值：

```text
u = clamp(已加速刻数 / 30, 0, 1)
s = 3*u*u - 2*u*u*u
speed = lerp(speed0, 21, s)
angle = 向锁定方向转动，但不超过本刻转角上限
velocity = direction(angle) * speed
```

14→21、30 刻时平均加速度约 0.233，连续曲线峰值约 0.35 像素/刻²，曲线两端斜率为零；收招对称地用较长时间插回 14。若前状态本身还在加速，这不自动保证跨状态加速度连续，但能避免速度值跳变。先让整理阶段稳定，再起冲更容易调。

不建议只对完整速度向量做固定 Lerp：反向向量会互相抵消，导致长虫几乎停车再掉头。保持速度、限制转角才能维持身体弧线。转弯半径近似 R=v/ω：速度 14、2°/刻约 401 像素；速度 21、0.5°/刻约 2406 像素。高速低转向意味着需要提前对齐，不能靠贴脸追踪补偿。

## 弹幕与路径需共同调参

1024 建议保留为弹幕资格范围：每次 Crash 选定一种攻击、只提交一次，在进入范围后按自身前摇释放，不要每刻重抽。第一次筛选建议让主体穿越和密集封位错开 15—25 刻；安全扇区、风刃入口或旋风收缩路径应至少留下一个能避开身体的方向。

光束和持续追踪激光的转向必须另有停止追踪时点；如果头部可持续拦截、光束继续瞄准、旋风又封掉侧向，就算头部只有 21 也可能无法躲开。弹幕射程、前摇、追踪能力未定，无法现在给出唯一“正确距离”。
