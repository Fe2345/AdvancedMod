## 关键数值证据

- 400当前生命的神圣汽化拟支付6，斩杀低生命目标实际支付1且只记录1；未成功命中不创建结界、不支付。
- 无防御白值100：融化175、导电125；经一个中继节点的下一目标87（原生整数截断），不因中继重复乘0.7。
- 150记录生命减抗3个百分点，750达到15个百分点；同队取最高，未组队玩家不共享，允许负抗。
- 龙卷100白值，在1000防御、100%测试抗性下，水增伤100%与擢升50%仍结算300；单独100%暴击用例结算200。
- 不连续选择同一敌人；两目标交替命中，剩余一个目标则终止。首个龙卷在首次满足150点后900刻触发，结束后重新计时，不扣记录生命。
- 非核心弦可覆盖同一直线的三个目标，单次满充能每目标只受一次伤害。

## 修正过程与边界

- 首轮实机15/16：高防御用例使用10000防御，触发原版`SuperArmor`专用保底分支。核查本机引擎后改为1000普通防御验证，16/16通过，随后补充暴击和实际计时至19项。没有将首轮失败写为通过，也没有为通过用例修改原版SuperArmor规则。
- 神圣龙卷忽略普通防御与Calculate抗性乘区，仍遵守引擎免伤、SuperArmor及伤害上限等独立规则；不宣称绕过任意Mod的伤害拦截。
- 100 mph约为19.5556像素/刻，45 mph为8.8像素/刻；依据本机原版速度仪的42240像素/英里与216000刻/小时换算。
- 结界状态及NPC伤害在权威侧执行，现有电弧使用起终点网络包；本轮未做双客户端、重连、晚加入专项，不将单人测试当作联机通过。
- 未验证复杂群怪的最优选线性能、持续长时战斗及其他Mod兼容。任意弦候选与组合搜索在小规模几何用例中通过，不承诺复杂场景无性能风险。
- 专用结界／龙卷特效、传送开关动画未制作；满充能暂复用已有电弧。该轮验证数值与结算，没有把电弧接入视为专门视觉验收。
