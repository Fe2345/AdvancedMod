# 天裁共鸣、招架与反击验收（2026-10-25）

## 实现与口径

- 共鸣元素逐Item保存，存档／克隆／网络序列化支持火、水、雷、冰；优先级岩浆→水→冰→云。
- 60刻共鸣动画：前15刻抬剑、15刻展开六把纯视觉简约剑，第30刻同一次更新提交Item元素与视觉颜色，后30刻反向收起。
- 持续右键格挡，本体无伤害；起手20刻完美窗口，冷却从起手计360刻。松开或一次成功即结束；完美刷新原连段期限，不自动攻击。
- 保留敌对弹幕伤害>1、速度×更新次数>1、尺寸向量长度<300的筛选。剑线与伤害源相交后，为该来源记录60刻、仅针对完成招架玩家的保护。
- 普通最终伤害减半，完美取消Hurt，避免原生最低1点伤害；不新增无敌帧。普通受击通过PostHurt恢复受击前的免疫状态，保留其他来源已有保护。
- 正面512半径半圆内有敌人才触发完美反击；沿格挡方向垂线±192生成双剑，各1.0倍率、零附着，独立追踪最近敌人。512仅为触发范围。
- 简约剑使用192×武器缩放的长线与柄部短横线。无共鸣青绿，共鸣后与武器元素一致；神圣性质明确不实现。

## 验证方式与范围

- 离线：`dotnet run --project Tests/Vfx/Vfx.Tests.csproj --no-restore -- docs/testing/2026-10-25-hallow-actions-offline.json`，31/31通过。
- 单人：`Tests/Run-HallowActionsLive.ps1` 在项目obj内的隔离存档启动真实tModLoader客户端。测试驱动向原生ItemCheck传入已转换的左右键状态，不直接调用武器Shoot。
- 水／岩浆使用受控wet／lavaWet状态；冰／云放置真实脚下方块。此测试确认环境选择到共鸣动作的链路，不宣称覆盖自然液体流动与入水检测。
- 招架由实际敌对弹幕／NPC和剑线相交触发；减伤断言使用带真实来源的Player.Hurt，比较同一来源未招架时的实际伤害。隔离世界为大师难度，不能把输入100直接视为弹幕最终伤害100。
- 用例间重置冷却用于隔离；另独立等待完整360刻，验证359刻不可重启、360刻可以重启。
- 反击弹幕通过真实NPC碰撞与伤害管线验证每把135伤害、零附着。

## 本轮发现与修复

1. 测试入口位于右键转换之后，最初只设置controlUseTile未能发起动作。核对本机原版ItemCheck后，改为注入起手altFunctionUse=1，由原版转为2；原始失败报告保留。
2. 最初按100伤害和屏幕竖直轴断言，未考虑大师难度弹幕倍率和原版发射点方向修正。改用同源实际伤害基线及相对锁定方向垂线断言。
3. 截图发现简约线段误用整张MagicPixel资源，产生巨大色块。修复为1×1源矩形，192长线与短柄尺寸恢复正常。
4. 冷却边界测试最初按测试阶段计数，误差一刻。改为记录实际持握弹幕生成时的GameUpdateCount；玩法计时公式未改动。
