## 测试口径

脚本通过原版 AI 生成完整链，然后以仅测试启用的 GlobalNPC 冻结运动以稳定观察。生命半血阶段为权威端定向设置，以隔离网络与绘制问题；单人另通过身体 SimpleStrikeNPC 验证真实共享生命入口。不是完整自然战斗回放。

联机使用真实本机 TCP 服务端与两客户端；第二客户端在首次召唤与初始同步之后加入，然后两端共同观察后续释放、击败与半血变化。该用例不等同于击败后才加入或重连专项。

## 调试记录

- 初次预览未指定 MagicPixel 的 1×1 源矩形，导致填充尺寸错误与放射线；修复后重新预览通过。
- 首轮实例测试从槽位 0 生成头部，原版身体将前节索引 0 判为无效，链随即消失；修正隔离脚本从槽位 1 生成。
- 中文独有键被 tML 本地化更新移除；补齐默认语言键并恢复作者提供的中文内容，最终图中文字正常。
- 图片查看链路曾显示部分文字／图标或整条缺失，但最终原始 PNG 解码后的像素实际完整。原图与重新编码版的全部 BGRA 像素 SHA256 一致，见 png-pixel-comparison.json；局部图 network-client*-detail.png 已目视检查。不能把查看工具的异常推定为游戏缺绘。
- 因此撤销临时独立 SpriteBatch 方案，恢复直接使用官方传入批次；最终复跑为 20261029-131229。保留当帧 PreDraw 检查及像素统计，避免失焦跳帧时截取旧缓冲。
