## 失败定位与修复

首轮弹幕在服务器上的 Profile 为 Unknown，虽然 TCP 接入及玩家状态同步成功，NPC 命中仍失败。原因是原版 NewProjectile 返回前已经发送首次包，而工具此前在返回后写入字段。最终改用 GlobalProjectile.OnSpawn 在首次发包前配置；撤销了生成后补发的过渡方案，避免远端先收到未配置弹幕。

复测发现服务器动画结束可能早于近战请求到达；现携带请求时剩余动画帧并限制其上限，服务器按游戏刻维护命中冷却。另补上服务器耗尽穿透时的弹幕销毁广播。

曾有两个客户端同时启动争用 steam_appid.txt 的环境失败，脚本现错开启动。专用服务器在重定向控制台时有“句柄无效”日志，但仍完成真实监听、接入和全部断言；不将该日志等同于测试失败。单人异常收尾用例主动抛出的预期异常已被用例捕获。

## 复现与边界

运行 Tests/Run-ElementNetwork.ps1 -TmlDirectory 指向已安装 TML；脚本自行构建打包，以 obj/element-live 的隔离存档为种子，每轮建立新的目录。三个进程分别产出报告，缺少报告、超时或任意 FAIL 都返回失败，并清理本轮进程。

主机模式、晚加入、断线重连、真实敌对弹幕的联机受伤、网络延迟／丢包、第三方效果和攻击回调兼容仍待专项验收。本次不是反作弊验收；攻击配置及玩家受伤保留 TML 的客户端信任边界。客户端库存与 CD 是每 6 刻同步的镜像，不负责裁定 NPC 反应。反应表现事件仍在结算端发布，未来 Effects 的跨端视觉事件另行接入。
