# 月曜度界面

## 当前实现（2026-11-01）

- 正式界面位于 `Basic/Graphics/UI/LunarEnergyUI.cs`，为月曜度专用原生 UI，不是通用框架。
- 读取 `PlayerSpecialState.LunarRate`，上限 `MAX_LUNAR_RATE = 720`；赋值约束到 0～720，NaN 归零。
- 月相以数学坐标 -3π/4 为轴，从屏幕左下起盈，亮起面积对应能量比例。银铜边框与星空背景保留作者已确认的首版效果。
- 图标位于小地图左侧，随 UI 缩放及地图缩放定位；小地图关闭或改为叠加模式时保留相同锚点。全屏地图和隐藏 UI 时暂不显示，状态不清除。
- 能量为零时暂隐藏图标及面板，正值恢复；只有点击图标改变面板展开状态，进出世界清理展开状态。背包开关和外部点击不收起面板。
- 面板基准尺寸 780×320（首版的横向3倍、纵向2倍），屏幕宽度不足时限制面板宽度，位置限制在屏幕内；极端尺寸下的文本布局仍需人工验证。

## 内容与选择

顶部小字显示 `月曜度：{LunarRate} / {MAX_LUNAR_RATE}`，最多显示两位小数。中部并排四个圆形按钮，分别使用原版日耀、星璇、星云、星尘碎片素材；选中项金色高亮。

点击按钮立即写入 `PlayerSpecialState.SelectedLunarSkill`，更新下面三行：

1. 能量消耗：X点
2. 被动：`Mods.AdvancedMod.LunarSkill.{SkillName}.Passive` 对应的本地化内容
3. 主动：`Mods.AdvancedMod.LunarSkill.{SkillName}.Active` 对应的本地化内容

`SkillName` 分别为 `Solar`、`Vortex`、`Nebula`、`Stardust`。技能名称使用同组 `DisplayName`。选中技能目前只是玩家状态，不实现技能效果、扣能、持久化或网络事务。

**必须后续替换：当前60／120／180／240点是UI预览模拟数据。技能模块实现后，必须直接引用对应技能模块的实际消耗变量，删除UI中的模拟表，禁止据此执行扣能结算。**

## 验证与试用

- 首版构建0警告0错误，客户端44项检查通过；作者已确认首版效果正确。本轮改变定位并增加内容后，构建0警告0错误，客户端44项检查通过；作者手测反馈“全部符合预期”，新版UI验收通过。
- `pwsh -File Tests/Run-LunarLive.ps1` 使用 `obj/lunar-live` 隔离存档，启动后保持窗口供作者测试，不向日常 Mods 目录部署。
- `/lunar 180`、`/lunar 720`、`/lunar 0` 可观察能量文字、月相和隐藏行为。该命令仅限单人开发测试。
- 手动检查：图标在小地图左侧且无重叠；四个技能的高亮、消耗与被动／主动文本一一对应；开关背包或操作未被面板覆盖的区域不会收起面板；再次点击月牙可关闭。
- 客户端自动报告写入 `obj/lunar-live/LunarCaptures/report.json`；自动断言不代替作者对文本布局、图标和交互的验收。
